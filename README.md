# Blazing Pizza — W03 Blazor Assignment

Blazing Pizza web application completed for the CSE 325 W03 assignment.

## Assignment changes

- Prices are displayed in Peruvian soles (`S/`).
- The footer includes Percy Yarleque and Peru.
- The application includes checkout, order history, route parameters, navigation, and a shared layout.

## Run the application

Requires the .NET 8 SDK.

```powershell
dotnet restore
dotnet run
```

Open the local address displayed in the terminal.
